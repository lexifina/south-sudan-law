# Section 137 — Using as True such Declaration Knowing it to be False
Whoever uses or attempts to use as true any of the declarations referred to in section 136, above, knowing the same to be false in any material point, commits an offence, and upon conviction, shall be sentenced in the same manner as if he or she gave false evidence.
Explanation—
A declaration, which is inadmissible merely upon the ground of some informality, is a declaration within the meaning of sections 136 and 137 of this Act.
