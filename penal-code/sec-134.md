# Section 134 — Issuing or Signing False Certificate
Whoever issues or signs any certificate required by law to be issued or signed or relating to any fact of which such certificate is legally admissible in evidence, believing or knowing that such certificate is false in any material point, commits an offence, and upon conviction, shall be sentenced in the same manner as if he or she gave false evidence. 135. Using as True a Certificate known to be False.
Whoever uses or attempts to use any such certificate as a true certificate knowing the same to be false in any material point, commits an offence and upon conviction, shall be sentenced in the same manner as if he or she gave false evidence.
