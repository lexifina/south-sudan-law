# Section 107 — Wearing Uniform or using Token used by Public Servant
Whoever not belonging to a certain class of public servants wears any uniform or carries any token resembling any uniform or token used by that class of public servants with the intention that it may be believed that he or she belongs to that class of public servants, commits an offence, and upon conviction, shall be sentenced to imprisonment for a term not exceeding six months or with a fine, or with both.
